# Inter

Unmodified Inter 4.1 variable web fonts from the official release:
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip

- `InterVariable.woff2`: normal style, weights 100–900.
- `InterVariable-Italic.woff2`: italic style, weights 100–900.
- `LICENSE.txt`: upstream SIL Open Font License 1.1 and copyright notice.

These fonts are bundled by Vite for offline use. The timer and compact metadata
keep their existing monospace stack.
